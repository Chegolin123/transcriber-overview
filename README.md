# Transcriber — обзор

Расшифровка видео и аудио через **faster-whisper** на своей видеокарте:
txt, srt и json с таймкодами. Без облака, без лимитов на минуты.

Приватный репозиторий: `Chegolin123/transcriber` — доступ по запросу.
Публичная реализация того же пайплайна: [whisper-gpu](https://github.com/Chegolin123/whisper-gpu).

## Задача

Часовая лекция или созвон должны превращаться в текст локально: облачные
сервисы считают минуты, требуют загрузки и не всегда доступны из региона.

## Пайплайн

```
медиафайл
   │
   ▼
ffmpeg (если контейнер не WAV)
   │
   ▼
faster-whisper medium, float16 на CUDA
   │  VAD: тишина отбрасывается
   ▼
сегменты с таймкодами
   ├── .txt   — сплошной текст
   ├── .srt   — субтитры
   └── .json  — сегменты + язык + длительность
```

## Инженерные детали

- Модель хранится локально: скачивание с HF из региона нестабильно.
- `float16` на GPU, `int8` на CPU — один и тот же код, разные профили.
- VAD с минимальной паузой 500 мс: без него тишина съедает половину времени.
- Сегменты пишутся по мере готовности, поэтому длинный файл не теряется при
  падении процесса.
- RTF (время расшифровки / длительность аудио) меряется отдельным скриптом:
  «быстрее реального времени» — это проверяемое утверждение, а не ощущение.

## Что осталось за кадром

Скачивание исходников из видеохранилищ адаптировано под конкретную сеть и
троттлинг. Это не публикуется: во-первых, ничего полезного для чужой сети, а
во-вторых, публичная часть — именно расшифровка.
